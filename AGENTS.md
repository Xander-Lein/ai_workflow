# Инструкции для агентов репозитория

## Назначение

Этот репозиторий содержит переносимые Cursor rules, skills, команды и шаблоны для AI-driven development.

## Правила изменений

- Перед изменением прочитай `README.md` и проверь `git status --short`.
- Новые skills размещай в `.cursor/skills/<skill-name>/SKILL.md`.
- Каждый `SKILL.md` должен иметь YAML frontmatter с `name` и `description`.
- Сохраняй `references/`, metadata, attribution и лицензии при переносе сторонних материалов.
- Не добавляй секреты, токены, историю терминалов, личные пути и настройки пользователя.
- Не дублируй инструкции без необходимости: общее поведение держи в rule, подробности — в skill, короткий запуск — в command.
- Отделяй рекомендации автора от собственных рекомендаций репозитория.

## Проверка

Перед коммитом запускай:

```bash
python scripts/check.py
```

Если изменён валидатор, проверь его на текущем репозитории и на временной минимальной структуре.

## Лицензии

Материалы Matt Pocock и других авторов не переписывай без необходимости. Сохраняй исходные ссылки, provenance и соответствующее уведомление об авторских правах.
