# /tdd-loop

1. Напиши автотесты под каждый пункт плана.
2. Запусти тесты и покажи красный статус (RED).
3. Пиши код и сам крути цикл «запуск тестов -> чтение ошибок -> починка», пока все тесты не станут зелеными (GREEN).

В конце покажи команды проверок, итоговый статус и оставшиеся ограничения. Не объявляй задачу готовой без зелёных автотестов или явно зафиксированного объяснения, почему тесты неприменимы.
