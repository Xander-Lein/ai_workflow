# /implement-spec

Реализуй утверждённую спецификацию как task graph:

1. Прочитай спецификацию и связанные задачи.
2. Определи независимые задачи и зависимости.
3. Для каждой задачи используй TDD и отдельную проверку.
4. После реализации проведи `classify-change` и `code-review`.
5. Интегрируй только проверенные результаты и запусти полный набор проверок.

Не начинай реализацию без утверждённой спецификации и не объявляй задачу завершённой без фактических результатов проверок.
