# /code-review

Проведи независимое ревью diff по двум направлениям:

1. **Standards** — соответствие правилам репозитория, читаемость и поддерживаемость.
2. **Spec** — полнота требований, регрессии, корректность поведения и существующие callers.

Для каждого finding укажи severity, файл или участок, доказательство и конкретное исправление. Отдельно перечисли проверенные команды и ограничения ревью. Не смешивай findings двух направлений.
